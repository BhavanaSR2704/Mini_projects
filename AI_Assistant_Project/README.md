# Smart AI Assistant using Flask

## Project Description

Smart AI Assistant is a simple web application developed using Python and Flask. It demonstrates Prompt Engineering concepts by providing different AI-based functions such as answering questions, summarizing text, creative writing, and study advice.

## Features

- Question Answering
- Text Summarization
- Creative Writing
- Study Advice
- User Feedback (Yes/No)

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Prompt Engineering

## How to Run

1. Install Python.
2. Install Flask.

```
pip install flask
```

3. Open the project folder in VS Code.
4. Run:

```
python app.py
```

5. Open your browser and visit:

```
http://127.0.0.1:5000
```
